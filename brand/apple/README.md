# Homebase — Apple icon appearances

Same mark as `../homebase-symbol.svg`, laid out for Apple's icon modes (iOS/iPadOS 18+, iOS/iPadOS/macOS 26).

| Appearance | Background | Glyph | File |
|---|---|---|---|
| Default (light) | `#d1ee97` | `#101113` | `icon-light.svg` / `AppIcon.appiconset/icon-light.png` |
| Dark | transparent (system adds dark gradient) | `#d1ee97` | `icon-dark.svg` / `icon-dark.png` |
| Tinted | black | white (grayscale; system applies the tint) | `icon-tinted.svg` / `icon-tinted.png` |
| Clear light / Clear dark | generated by Icon Composer from the layers | | `icon-composer/` |

All artwork is 1024×1024, square, no rounded corners (the system applies the mask).
The glyph sits at 74 % scale, the same placement as `../homebase-app-icon.svg`.

## Xcode (iOS/iPadOS 18+)
Drop `AppIcon.appiconset/` into `Assets.xcassets`. Default, Dark and Tinted are already wired up in `Contents.json`.

## Icon Composer (iOS/iPadOS/macOS 26: Liquid Glass, Clear, Tinted)
1. New icon, then set the background fill to `#d1ee97` (or import `icon-composer/background.svg`).
2. Add `icon-composer/glyph.svg` as a single layer in one group.
3. Dark appearance: glyph fill `#d1ee97`, background `#151619`.
4. Leave Clear and Tinted automatic. The glyph is one solid shape, so the glass treatment reads cleanly.
5. Save as `AppIcon.icon` and add it to the Xcode project (one file covers iPhone, iPad and Mac).

`preview-appearances.png` is a CSS approximation of all six looks. Check the real glass result in Icon Composer's preview.

## Web app (PWA) limitation
Home-screen web apps get one `apple-touch-icon` only. Safari has no way to supply dark, tinted or clear variants,
so iOS derives them automatically. These variants take effect only in a native or wrapped build (Xcode, Capacitor and similar).
